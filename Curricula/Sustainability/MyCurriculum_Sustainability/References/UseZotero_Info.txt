Install
Zotero for Linux
##################
https://www.zotero.org/download/

Zotero 10 for Linux
Zotero-10.0.1_linux-x86_64.tar.xz


For Ubuntu and other distros that support .desktop files, the tarball includes a .desktop file that can be used to add Zotero to the launcher:

    *Move the extracted directory to a location of your choice (e.g., /opt/zotero).
$ sudo mv Zotero_linux-x86_64 /opt/Zotero


    *Run the set_launcher_icon script from a terminal to update the .desktop file for that location. .desktop files require absolute paths for icons, so set_launcher_icon replaces the icon path with the current location of the icon based on where you’ve placed the directory.
$ chmod +x set_launcher_icon
$ ./set_launcher_icon

    *Symlink zotero.desktop into ~/.local/share/applications/
$ ln -s /opt/zotero/zotero.desktop ~/.local/share/applications/zotero.desktop

Zotero should then appear either in your launcher or in the applications list when you click the grid icon (“Show Applications”), from which you can drag it to the launcher.

Add Zotero to Firefox
################

Go to the Zotero Download Page if you have not installed the connector yet, and click Install Connector for Firefox. 
	https://www.zotero.org/download/

Click Add or Allow when Firefox prompts you to permit the extension.

Click the Extensions button (shaped like a puzzle piece) in the top-right corner of the Firefox toolbar.

Find the Zotero icon in the drop-down list.Click the gear icon next to Zotero and select Pin to Toolbar.
