**What happened**

When a turn ends with `stop_reason == "pause_turn"`, `run_batch_mode` appends the model's entire previous output to `messages` and submits a new batch. That output includes:

- every `web_search_tool_result` block (up to 25 searches, each with many results, plus encrypted content that the API needs back)
- every code execution result and thinking block

All of that counts as input tokens on the next request. Your prompt asks for a literature review plus two infographic scripts, with 25 web searches and up to 10 continuations allowed, so the context snowballs. At some point the resubmitted conversation hit 1,037,825 tokens, over the 1,000,000 limit, and the API rejected it before doing any work. The batch you listed (`total=1, errored=1`) was one of those continuation batches, not the first one.
