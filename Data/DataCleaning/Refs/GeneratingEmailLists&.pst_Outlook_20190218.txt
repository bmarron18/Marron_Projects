-------- Process the output .csv in Linux to generate EmailLists ---------------------------------

1. If needed, 
	a. change end of line CRLF ==> LF
dos2unix test.csv

	b. change encoding WINDOWS-1258 ==> UTF-8
iconv -f WINDOWS-1258 -t UTF-8 test.csv -o test_v1.csv


2. Delete header so that Line 1 starts with data. 

For example,
Oregon Clean Vehicle Rebate - Phase I Application

3. check line distance between replicate fields. For example, if first field of interest 
is "Submitted: <date>" this appears regularly every 14 lines


4. Add returns to set the .csv file for the correct line distance between desired fields. 

5. Extract lines and look for breaks (ie where there is an incongruity in output)
https://unix.stackexchange.com/questions/369181/printing-every-nth-line-out-of-a-large-file-into-a-new-file

$ sed -n '0~14p' Modified_Phase1ApplicantData.txt > Email.txt

		0~14p 	==> select and print every 14th line, beginning at line 0. 
		Line 0 	==> has nothing, so the first printed line is line 14.
		-n 		==> only explicitly printed lines are included in the output

	# another option. USE THIS!
$ awk 'NR % 14 == 0' input > output		
		
		
6. Modify .txt file by making entry format identical at incongruities. Can search the output by 
multiplying line distance by field distance (eg, line number at incongruity x 14)


7. Remove "Name" and "Email" or other repeated label
	
	
8. Remove duplicate entries
https://unix.stackexchange.com/questions/30173/how-to-remove-duplicate-lines-inside-a-text-file

$ uniq Phase1_Email.txt --count
$ uniq Phase1_Emails.txt > Phase1_EmailList_Unique_20190110.txt

	# another option
$ sort -u big-csv-file.csv > duplicates-removed.csv



	
9. Remove whitespaces, remove misc, and build a .csv for import into Outlook

	# eliminate all white spaces (not including TABs) 
$  to add

	# eliminate tabs at the beginning of all lines
$ sed -i 's/^[ \t]*//g' Phase1_EmailList_Unique_20190110.txt

	# remove tabs at the end of all lines
$ sed -i 's/[ \t]*$//g' Phase1_EmailList_Unique_20190110.txt

	# add a comma at the end of each line
$ sed 's/$/,/' Phase1_EmailList_Unique_20190110.txt > Phase1Email_Unique_20190110.csv

	# remove all <mailto:...>
$ sed -i 's/<.*>//g' Phase1Email_Unique_20190110.csv

	# open .csv in Notepad++ and add header (first line) for import into Outlook
EmailList_Phase1,

	# change to DOS format
$ unix2dos Phase1Email_Unique_20190110.csv

		=hyperlink("mailto:"&A2) (replacing A2 with whatever cell you are interested in)
		copy the formula down the rest of the 200 entries.
